- Responsive interface with light and dark themes.
- User-friendly notifications and interaction feedback.

**Engineering Focus**

- REST-oriented backend development.
- Document-based database modeling with MongoDB.
- Separation of application logic and presentation.
- Authentication, input validation, and data consistency.
- Iterative UI development and debugging.

**Future Improvements**

- Automated tests and continuous integration.
- Transaction integrity and stronger authorization checks.
